# CrossProfit AI · 3–5 分钟比赛演示

## 0:00–0:30 问题

打开 Dashboard：平台总说“参加活动有更多流量”，但小卖家常常有 GMV、没利润。CrossProfit AI 不聚合活动，而是在报名之前把真实利润算清楚。

## 0:30–1:20 TikTok 高流量案例

点击顶部“加载演示案例” → `TikTok Summer Mega Sale`，进入四步分析流程。指出 25% 折扣、12% 达人佣金、3% 活动佣金已结构化，平台配置与商品本体成本分开。点击“开始盈利分析”。

先停在顶部结论：风险标签、单件利润、利润率、预计总利润和盈亏平衡活动价，让评委在数秒内理解。

## 1:20–2:20 可解释与策略

展示成本瀑布：售价经过平台费、达人、采购、物流、关税、支付、汇损和退货准备金后才得到真实利润。打开“计算说明”，强调每一项有公式；AI 不做数学。

打开“策略建议”，现场把物流下降或达人佣金调低后重算。展示建议来自确定性事实，而不是泛泛聊天。

## 2:20–2:55 敏感性

打开敏感性分析。解释乐观/基准/悲观同时改变销量、退货率和物流成本，系统直接回答“悲观情况下是否仍盈利”。

## 2:55–3:35 多活动比较

进入“活动对比”，勾选三个案例。指出 Amazon 活动销量不一定最高，但利润率和总利润更健康；表格有文字风险级别，不只靠颜色。

## 3:35–4:10 极端亏损案例

返回活动分析加载 `TikTok Creator Flash Sale`：30% 折扣、20% 达人佣金、800 单。分析后强调红色提示：**负单件利润不会因为销量增长而改善，销量越大只会亏得越多。**

## 4:10–4:30 导出与结束

点击“导出 Excel 报告”，说明其中有 Summary、Cost Breakdown、Scenario Analysis、Recommendations 四个 Sheet。

结束语：**我们不是告诉卖家哪里有活动，而是告诉卖家这个活动值不值得参加。**

## 网络失败备用演示

切换“读取活动 URL”，输入受限页面并粘贴少量规则。展示系统不会抛出 403，而是说明页面可能需要登录，保留已识别字段并列出每个缺失项“为什么需要”和默认处理方式。整个演示无需网络和 API Key。
